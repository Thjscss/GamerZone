# GamerZone

E-commerce de accesorios gamer (mouses, teclados y auriculares) desarrollado como proyecto del curso de React de Coderhouse.

## Tecnologías
- React
- Vite
- JavaScript
- ESLint

## Cómo ejecutarlo
1. Clonar el repositorio
2. Instalar dependencias: `npm install`
3. Iniciar el servidor de desarrollo: `npm run dev`
